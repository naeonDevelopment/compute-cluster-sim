# Contributing

Read agent/contract.md and preserve the independent generic scope. Contributions
must be original or have explicitly reviewed provenance and compatible licensing.
All examples are synthetic; do not introduce proprietary fixtures, site-specific
profiles, credentials or upstream source copies. Original contributions are
Apache-2.0; preserve the copyright and licence notices.

This work order permits edits only in its dated worktree. Vagus owns commits.
Do not commit, configure remotes, push, open PRs, merge, deploy, spend, dispatch
model workers or run product code/tests/builds locally. Do not access siblings,
private memory, global history or owner-only projects. No .manna files.

Changes to scheduling, numeric parsing or accounting need independently reviewed
specification witnesses, including boundary and conservation cases. New tests,
schemas, expected values and workflow gates remain HELD until independently
reviewed; the author cannot self-approve judge surfaces. Qualified self-hosted
execution and review evidence must precede any validation claim. Documentation,
JSON syntax, structure and whitespace inspections can be performed locally.
